# Repository contribution rules

## Git commits

- Every commit message must follow [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/).
- Use the form `<type>[optional scope]: <description>` and include a `BREAKING CHANGE:` footer or `!` marker when applicable.
- Prefer focused commits and use standard types such as `feat`, `fix`, `docs`, `test`, `refactor`, `build`, `ci`, and `chore` according to the change's intent.
- Do not add Codex, AI assistants, or automated tools as authors, co-authors, sign-offs, or attribution in commit messages unless the user explicitly requests it.
